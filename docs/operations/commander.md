# PTW Result service operations

Build Linux/amd64 `ptw-commander`, `ptw-validation`, and
`ptw-owner-gateway` images off-host with one matching non-`latest` tag.
Production starts images with `--no-build` in one locked serial release.

The independent bridge remains under `/opt/ptw/platform`; do not merge its Git
history or database with this repository. Upgrade its worker first, then API,
apply its additive idempotency migration, and verify capabilities contain
exactly four JSON modes and one media mode. Run Product Brief, candidate,
digest-mapped critic JPEG, and authenticated asset canaries before resetting
the application schema.

After cutover run the dependency audit, public console Auth/App Check/CORS
audit, owner browser journey, skill/corpus verification, emergency Telegram
canary, deliberate restart recovery, and `scripts/audit_ptw_1gb.sh`. Repeat the
locked resource audit after 24 hours.

Logs use run, candidate, critic pass, action, provider invocation, recipe,
render, and final Creative IDs. Do not log prompts containing source contents,
credentials, attachment base64, or generated bytes.
