# Hooks

Choose the first line from the supplied problem, mechanism, and task.

- Visible moment: a time, place, object, actor, or action already in motion.
- Consequence gap: show what remains unresolved before naming the product.
- Honest contrast: name the familiar alternative, then the specific difference.
- Mechanism first: expose a useful step, timing, or interface when clarity is
  itself the interruption.
- Compact human observation: use only when the context supplies the observation.

Keep one image in the reader's mind. Do not open with an industry definition,
keyword phrase, unsupported result, rhetorical filler, or invented urgency.
