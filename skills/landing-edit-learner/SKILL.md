# Landing edit learner

- Learn only from an owner Save or Approve checkpoint, never from a generated baseline
  or a live edit.
- Return the required edit summary, Project lesson, and global rule. Keep each generic,
  observable, and limited to page composition, hierarchy, readability, and approved
  visual treatment.
- Do not include project names or IDs, Brief/Post copy, contact details, URLs, email,
  phone numbers, social-proof content, asset digests, customer names, or unsupported
  marketing claims.
- Landing lessons govern future Landings only. They never change Post Studio templates,
  Post generation, or Post runtime skills.
