# Post copy style anchors v1

Read this complete reference for `instagram_static_ad_v1`,
`tiktok_photo_post_v1`, and loopback `universal_ad_experiment_v1` candidate
generation. It is not input for `marketing_copy_v1`.

These are verbatim visible-copy anchors from owner-selected, Git-pinned source
projects. Learn their structure and rhythm. Never transfer a source product's
name, facts, audience, metrics, testimonial, offer, CTA, or brand vocabulary
into another Project. Write new copy using only the approved Product Brief and
task. The Product Brief language is authoritative even when an anchor or the
original idea uses another language.

## Candidate application

- `hook` and `headline`: one observable moment, contrast, or concrete
  mechanism. Do not combine several anchors.
- `primary_text` and `supporting_text`: reveal how the approved promise happens
  using supplied actors, timing, sequence, or reassurance.
- `caption`: extend the same idea from friction to mechanism to exact offer and
  exact CTA without repeating the headline in different words.
- `offer` and `cta`: preserve the Product Brief values byte-for-byte; anchors
  never authorize adapting them.
- `alt_text`: describe the exact resolved visual factually. Do not apply
  marketing tension, borrowed claims, or slogan rhythm to accessibility text.
