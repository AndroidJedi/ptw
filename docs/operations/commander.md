# PTW Result service operations

Build Linux/amd64 Commander, Validation, and Owner Gateway images off-host with
one matching non-`latest` tag. Production starts them serially with `--no-build`.

The unrelated bridge remains under `/opt/ptw/platform`. Before a future rollout,
its API/worker must independently advertise only Product Brief, Brief revision,
and Candidate generation JSON modes. Run real domain canaries plus authenticated
five-Creative asset/export checks before an authorized Commander reset.

After cutover verify the owner browser journey through awaiting review, all three
web actions, learning/graph persistence, child failure semantics, notification
delivery/ambiguity/manual retry, restart recovery, current PWA cache, skill and
schema checks, dependency audit, and resource audit.

Logs use Project, Brief, run, Creative, review action, feedback, WeightUpdate,
learning rule/snapshot, notification receipt, provider invocation, recipe,
render, and outcome IDs. Never log source-bearing prompts, credentials, media
base64, generated bytes, or Telegram tokens.
