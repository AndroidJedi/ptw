# PTW reaction stickers

These twelve original reaction characters were generated for the PTW Story
Studio with OpenAI's built-in image-generation tool. They use a shared matte
3D toy direction and do not reproduce existing meme characters or third-party
artwork.

Each source was generated against a flat chroma-key background, converted with
the Codex image-generation skill's soft-matte and despill workflow, visually
checked, and normalized to a 512 x 512 transparent PNG.
