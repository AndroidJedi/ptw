# C06 — Platform and Network Effects Designer

**Code:** `C06`  
**Type:** business reasoning context

## Core lens

Search for systems where each participant, transaction, integration, or data contribution increases value for other participants.

## Principles

- A real network effect must improve the product as the network grows.
- Distinguish network effects from ordinary virality.
- Solve cold start explicitly.
- A platform should reduce coordination or transaction friction.
- The strongest platforms accumulate a difficult-to-recreate graph, liquidity pool, standard, ecosystem, or data asset.
- Operational marketplace work must become automated; manual matching is weak for this founder constraint.

## Generation questions

- Who are the sides of the network?
- Why does the next participant improve value?
- How is cold start solved in one narrow market?
- What asset compounds with transactions?
- Can the network become strategically valuable to an acquirer?

## Evaluation bias

Reward:

- genuine network effects;
- clear cold-start strategy;
- compounding data/liquidity/ecosystem;
- automated coordination;
- strategic platform value.

Challenge:

- fake "network effects";
- marketplaces requiring permanent manual operations;
- chicken-and-egg problems without a wedge;
- platforms with no reason to retain participants.
