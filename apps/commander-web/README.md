# PTW Owner Console

The authenticated PWA exposes five workspaces. A global Validation Project
switcher scopes the first four and persists in the URL; Admin remains global.

1. Product Briefs — create one Project plus one hypothesis from one raw idea,
   review its immutable Brief history, and approve only after confirming its promise and offer.
2. Ad Studio — manually compose framed Instagram/TikTok recipes, save reusable
   Project templates, render authenticated JPEG/MP4 artifacts, and publish reviewed training examples.
3. Ads — review the selected Project's human-labelled generation history, exact authenticated JPEGs,
   Pexels attribution, copy, UUIDs, retries, feedback, and lesson proposals.
4. Landing — truthful inactive `Stage 3 pending` placeholder.
5. Admin — jobs, documentation, health, emergency stop, and guarded reset.

The browser does not perform market research, SEO, YouTube calls, image
generation, publishing, traffic, campaigns, UTMs, analytics, conversion
tracking, or active Landing work. Domain state and reviewed image bytes remain
authoritative in PostgreSQL behind Owner Gateway.

Active console chrome is strictly black, white, and neutral gray. Selected,
successful, failed, and destructive states use contrast, borders, patterns,
icons, and text rather than chromatic accents. Reviewed Ad photos remain
unaltered.

Run the active checks with:

```sh
npm run check
npm run test:e2e
```
